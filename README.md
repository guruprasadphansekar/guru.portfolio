# Guruprasad Phansekar — Portfolio

Architect & Urban Planner portfolio website. Single-file static site (all images are embedded, no build step needed).

## 🔗 Live site
Once GitHub Pages is enabled (see below), your site will be live at:
`https://<your-username>.github.io/<repo-name>/`

## 🚀 How to publish with GitHub Pages
1. Create a new repository on GitHub (e.g. `portfolio`).
2. Upload `index.html` to the root of that repository.
3. Go to the repo's **Settings → Pages**.
4. Under **Build and deployment → Source**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait 1–2 minutes, then visit `https://<your-username>.github.io/<repo-name>/`.

## 📁 Files
- `index.html` — the entire site (HTML, CSS, JS, and images all in one file).
